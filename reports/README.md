# Reports

**[`technical_report.md`](technical_report.md)** is the deliverable — the
6-8 page report covering problem framing, cleaning decisions, the churn
model, segmentation, key findings, and three recommendations.

[`supporting_analysis/`](supporting_analysis/) holds the working notes the
technical report (and the dashboard's "How this works" tab) refer back to for
detail on specific decisions:

- `data_quality_notes.md` — raw data issues found and how they were handled
- `churn_definition.md` — how `blended_churn` was defined and why
- `churn_model_summary.md` — model setup, performance, feature importance
- `segmentation_summary.md` — the 5 behavioral segments
- `value_trajectory.md` — the CLV x churn-risk framework
- `retention_playbook.md` — the 7 retention action groups
